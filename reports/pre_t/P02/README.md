## 数据与排版说明

文件根据本次上传的七张 P02 PDF 和逐基因统计输出排版。主图选择八个代表基因；细胞级差值按原图三位小数展示，样本级差值读取自统计输出。主图富集面板选取六个已有 term 展示命中计数，没有重新开展子集富集或显著性检验。原始完整分面保留在补充图中。

全部核心基因的样本级校正 q 值为 0.72–1.00；图中保留了这一解释限制。当前结果用于描述细胞级探索性 APA 变化，不能视作已完成跨样本验证。
